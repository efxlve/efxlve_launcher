Efxlve IGDB proxy

Running.

This service is the metadata transport for the Efxlve Launcher. It holds the Twitch credentials server-side so launcher users never register a Twitch application themselves.

Endpoint: /api/igdb?endpoint=games&q=<apicalypse query>

Responses are cached at the edge for a day, which keeps the IGDB rate limit free for cache misses. Data by IGDB.
