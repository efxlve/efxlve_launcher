## Üst bara karakter kazandırma (3. tur — "ruhsuz/kütük" düzeltmesi)
- §72'deki aşırı sadeleştirme kullanıcı tarafından *"çok ruhsuz, kütük duruyor"* bulundu.
- **Ders:** AI klişelerini sökmek ≠ ruhsuz bırakmak. Karakter gradyandan değil; **yüzey dilinden, tipografiden, derinlikten ve tek özgüvenli vurgu renginden** gelir.
- Uygulananlar:
  - **Tuş (keycap) yüzey dili:** tüm etkileşimli öğeler düz dolgu `#14161d` + 1px kenarlık + `inset 0 1px 0 rgba(255,255,255,0.045)`; basınca `translateY(1px)`.
  - **Gerçek derinlik:** `#titlebar` içeriğe gölge düşürüyor (`0 14px 26px -20px #000`), segment yuvası çukur (`inset 0 2px 5px -1px rgba(0,0,0,0.85)`). Glow değil, gölge.
  - **Tek vurgu rengi `#7f6ce8`, hep düz, sadece 3 yerde:** aktif sekme alt çizgisi (`.nav-seg-indicator::after`), `.logo-mark` ikonu, girişliyken avatar baş harfi + kenarlığı (+ aktif ayarlar ikonu).
  - **Tipografik ses:** sekmeler UPPERCASE 11px/700/ls 0.95px. `lang="tr"` sayesinde "İNDİRMELER" doğru büyüyor.
  - **Durum ışığı:** sabit LED halosu (`0 0 0 3px rgba(...,0.14)`), nabız yok.
  - **Tek hareket:** kayan karo `cubic-bezier(0.34, 1.22, 0.64, 1)` hafif overshoot.
  - Bar 48 → 50px.
- Ölçüm: 1024px'te seg=355 + right=171 (216px boşluk) — taşma yok. Eşikler değişmedi.
